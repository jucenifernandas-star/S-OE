📋 Como estruturar a planilha

A planilha deve ter uma aba por região (BR, SP, RJ, MG, BA, GO, ES, NO). Em cada aba, organize os dados em colunas com a primeira linha de cabeçalho contendo os nomes das métricas. A primeira coluna deve ser a Semana.

Métricas reconhecidas (use exatamente estes nomes nas colunas): Semana, Expedidas, SOP, Demanda, Headcount, Produtividade, CorteUn, CortePct, RupturaCD, RupturaLoja, DemandaSolicitada, UnSepPega, UnExpedidas, VendaLoja, SkusRecebidos, UnRecebidas, BacklogUn, BacklogSku, Estoque.

❄️ Dados de Termolábeis

Upload separado para o painel de Termolábeis (capacidade, estoque e ocupação da câmara fria). A planilha deve ter as colunas: Data, Estoque, CamaraFria, Contingencia. Cada linha é uma data do período.
